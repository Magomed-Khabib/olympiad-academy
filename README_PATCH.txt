ИСПРАВЛЕННАЯ ДЕМО-ВЕРСИЯ OLYMPIAD ACADEMY

1. Распакуй архив полностью.
2. Открой index.html в современном браузере на том же компьютере.
3. Войди в демо-админку:
   Email: admin@olympiad.local
   Пароль: Admin123!
4. Открой «Панель администратора» → «Создать код доступа».
5. Выбери «Код участника» или «Код администратора» и нажми «Сгенерировать код».
6. Скопируй код из всплывающего окна. Это и есть код для регистрации.
7. Выйди из аккаунта, открой «Регистрация» и введи этот код.

Важно: это только локальный прототип. Данные хранятся в localStorage конкретного браузера и не синхронизируются между устройствами. Пароли не защищены сервером. Не используй настоящие персональные данные до подключения backend и безопасной базы данных.
