# Olympiad Academy — стартовый прототип

## Быстрый запуск на Windows
1. Распакуйте архив в отдельную папку.
2. Дважды нажмите `index.html` — интерфейс откроется в браузере.
3. Для демонстрационного входа используйте:
   - Email: `admin@olympiad.local`
   - Пароль: `Admin123!`

## Что работает в прототипе
- адаптивный интерфейс для компьютера и телефона;
- пять вкладок: Главная, Профиль, Предметы, ИИ-помощник, Подготовка;
- демонстрационная регистрация по коду участника;
- профиль с ФИО, школой, классом и буквой;
- панель администратора, поиск учеников, создание кодов и блокировка/разблокировка;
- формы плана подготовки и выбор файла для будущей отправки в ИИ.

## Важно перед публикацией
Это **фронтенд-прототип**, не готовая защищённая система. Данные сейчас находятся в localStorage этого браузера, а пароль администратора демонстрационный. Не размещайте реальные персональные данные и не используйте прототип для настоящих аккаунтов.

Перед публичным запуском необходимо:
- подключить backend и базу данных;
- хранить пароли только в виде безопасных хешей;
- проверять роль администратора на сервере;
- сделать одноразовые/сроковые коды приглашения;
- реализовать восстановление пароля и безопасные сессии;
- подключить ИИ API и серверную обработку загружаемых файлов;
- включить HTTPS и правила конфиденциальности.

## Android
`manifest.webmanifest` — начальная настройка PWA. Для установки с сайта на Android понадобится размещение через HTTPS и service worker; APK можно собрать отдельным этапом после подключения backend.
