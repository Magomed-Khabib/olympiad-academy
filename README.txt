Important:
This is a front-end demonstration. Accounts, access codes, plans and chat history are stored in localStorage in the current browser only.
Do not use real passwords or sensitive student information. For production, move authentication, access-code validation, user records, and AI requests to a secure backend with a database. Never place AI API keys in app.js.

To test locally, open index.html in a browser. For PWA/service worker/offline install behavior, serve over HTTPS or localhost.
